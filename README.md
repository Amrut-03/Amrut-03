### 👋 About me

I build production Flutter apps with **Clean Architecture, BLoC/Riverpod and Firebase**, and I'm focused on **on-device AI**: running LLMs, embeddings and retrieval locally so user data never leaves the phone.

- 🧠 Built a fully on-device RAG assistant: MiniLM embeddings, hybrid vector + keyword retrieval, local LLM with a low-RAM fallback
- 📦 Author of [`flutter_body_part_selector`](https://pub.dev/packages/flutter_body_part_selector) on pub.dev
- 💼 Software Engineer at Mitt Arv (2025–2026), plus two earlier Flutter internships
- 🎯 Open to **Flutter** and **AI mobile app** roles
